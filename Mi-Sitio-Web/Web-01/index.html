Aprende SQL Server de Forma Sencilla

Bienvenido a la guía interactiva paso a paso. Diseñada para comprender el mundo de las bases de datos relacionales sin complicaciones técnicas.

🗄️

¿Qué es una Base de Datos?

Es un almacén organizado de información digital. Piensa en ella como una hoja de datos veloz y segura donde puedes almacenar usuarios, registros o productos.

⚙️

¿Qué es SQL Server?

Es un sistema de gestión de bases de datos relacionales (RDBMS) desarrollado por Microsoft. Permite administrar grandes volúmenes de información de manera eficiente.

Instalación de SQL Server en Linux (Ubuntu)

SQL Server puede ejecutarse en distribuciones Linux como Ubuntu 22.04 LTS. A continuación verás la secuencia de comandos requerida en la terminal.

🐧

Requisito Previo

Asegúrate de contar con al menos 2 GB de memoria RAM libre y permisos de superusuario (sudo) en el sistema.

1. Importar repositorio público y claves

Terminal Bash 
wget -qO- https://packages.microsoft.com/keys/microsoft.asc | sudo apt-key add -
sudo add-apt-repository "$(wget -qO- https://packages.microsoft.com/config/ubuntu/22.04/mssql-server-2022.list)"

2. Instalar y configurar el paquete

Terminal Bash 
sudo apt-get update
sudo apt-get install -y mssql-server
sudo /opt/mssql/bin/mssql-conf setup

Creación de Bases de Datos y Tablas

El lenguaje DDL (Data Definition Language) permite estructurar los contenedores y esquemas donde residirán los datos.

1. Crear Base de Datos

Crea el contenedor principal con el comando CREATE DATABASE.

CREATE DATABASE SistemaUsuarios;
GO
USE SistemaUsuarios;
GO

2. Crear Tabla con Atributos

Define columnas, tipos de datos y restricciones básicas.

CREATE TABLE Usuarios (
    UsuarioID INT PRIMARY KEY IDENTITY(1,1),
    Nombre VARCHAR(100) NOT NULL,
    Email VARCHAR(150) UNIQUE NOT NULL,
    Edad INT,
    PrecioUltimaCompra DECIMAL(10,2),
    FechaRegistro DATETIME DEFAULT GETDATE()
);
GO

Consultas Básicas en SQL (CRUD)

DML (Data Manipulation Language) engloba las operaciones de inserción, consulta general, actualización y eliminación de registros.

1. Insertar Registros (CREATE)

INSERT INTO Usuarios (Nombre, Email, Edad, PrecioUltimaCompra)
VALUES ('Lucas Gómez', 'lucas@example.com', 22, 1500.50),
       ('María Silva', 'maria@example.com', 30, 3200.00),
       ('Carlos Pérez', 'carlos@test.com', 17, 800.00);

2. Consultar Todos los Datos (READ)

SELECT * FROM Usuarios;

3. Actualizar Registros (UPDATE)

UPDATE Usuarios
SET Nombre = 'Lucas Ariel Gómez', Edad = 23
WHERE UsuarioID = 1;

4. Eliminar Registros (DELETE)

DELETE FROM Usuarios
WHERE UsuarioID = 3;

Filtrado de Resultados con Condicionales

La cláusula WHERE permite extraer unicamente los registros que cumplan criterios específicos, optimizando las consultas.

Operadores de Comparación y Lógicos

Filtros numéricos y lógicos (AND / OR) 
-- Usuarios mayores de edad con compras superiores a $1000
SELECT Nombre, Edad, PrecioUltimaCompra 
FROM Usuarios 
WHERE Edad >= 18 AND PrecioUltimaCompra > 1000;

Búsqueda de Patrones con LIKE y Comodines

Filtros de texto con LIKE 
-- Buscar correos pertenecientes al dominio 'example.com'
SELECT Nombre, Email 
FROM Usuarios 
WHERE Email LIKE '%@example.com';

Filtrado con RANGOS (BETWEEN) y LISTAS (IN)

Filtros con BETWEEN e IN 
-- Usuarios entre 20 y 40 años
SELECT * FROM Usuarios WHERE Edad BETWEEN 20 AND 40;

-- Filtrar usuarios por una lista específica de IDs
SELECT * FROM Usuarios WHERE UsuarioID IN (1, 5, 8, 12);

Ordenamiento de Resultados (ORDER BY)

La cláusula ORDER BY organiza el conjunto de datos retornado de forma ascendente (ASC) o descendente (DESC). Se combina con TOP u OFFSET/FETCH para paginación.

1. Ordenar por una o varias columnas

-- Ordenar de mayor a menor según la edad
SELECT Nombre, Edad, Email 
FROM Usuarios 
ORDER BY Edad DESC;

-- Ordenar por Edad (Ascendente) y luego por Nombre (Ascendente)
SELECT Nombre, Edad 
FROM Usuarios 
ORDER BY Edad ASC, Nombre ASC;

2. Limitar Resultados con TOP

-- Obtener únicamente los 5 usuarios que más dinero gastaron
SELECT TOP 5 Nombre, PrecioUltimaCompra 
FROM Usuarios 
ORDER BY PrecioUltimaCompra DESC;

3. Paginación con OFFSET y FETCH

-- Saltar los primeros 10 registros y obtener los siguientes 5
SELECT UsuarioID, Nombre 
FROM Usuarios 
ORDER BY UsuarioID ASC 
OFFSET 10 ROWS FETCH NEXT 5 ROWS ONLY;

Funciones de Agregación

Las funciones de agregación efectúan cálculos matemáticos o estadísticos sobre un conjunto de filas y devuelven un único valor resumido.

📊 COUNT()

Cuenta el total de filas o registros que coinciden con la consulta.

💵 SUM()

Suma todos los valores numéricos de una columna determinada.

📈 AVG()

Calcula el promedio aritmético de los valores numéricos de la columna.

📉 MIN() / MAX()

Encuentra el valor mínimo o máximo dentro de una columna.

Ejemplo Unificado en SQL

Cálculos Estadísticos 
SELECT 
    COUNT(*) AS TotalUsuarios,
    SUM(PrecioUltimaCompra) AS TotalVentas,
    AVG(PrecioUltimaCompra) AS PromedioVenta,
    MIN(Edad) AS EdadMinima,
    MAX(Edad) AS EdadMaxima
FROM Usuarios;

Agrupamiento de Resultados (GROUP BY & HAVING)

GROUP BY colapsa filas con valores idénticos en filas de resumen. Para filtrar los grupos ya resumidos se utiliza HAVING (en lugar de WHERE).

1. Agrupar Registros con GROUP BY

-- Agrupar usuarios por edad y contar cuántos hay de cada edad
SELECT Edad, COUNT(*) AS CantidadUsuarios
FROM Usuarios
GROUP BY Edad;

2. Filtrar Grupos con HAVING

Diferencia entre WHERE y HAVING 
-- Obtener edades cuyo promedio de compra sea mayor a $2000
SELECT Edad, AVG(PrecioUltimaCompra) AS PromedioGasto
FROM Usuarios
WHERE Edad >= 18 -- Filtra filas antes de agrupar
GROUP BY Edad
HAVING AVG(PrecioUltimaCompra) > 2000; -- Filtra los grupos formados

Claves Primarias y Foráneas (Relaciones)

Las relaciones integran la integridad referencial en las bases de datos relacionales, conectando registros de distintas tablas.

🔑

Clave Primaria (Primary Key)

Campo único que identifica cada fila de una tabla sin duplicados ni valores nulos.

🔗

Clave Foránea (Foreign Key)

Columna que apunta a la Clave Primaria de otra tabla, asegurando la coherencia de los datos.

Ejemplo: Vincular la Tabla Publicaciones con Usuarios

CREATE TABLE Publicaciones (
    PublicacionID INT PRIMARY KEY IDENTITY(1,1),
    Titulo VARCHAR(200) NOT NULL,
    Contenido TEXT,
    UsuarioID INT,
    CONSTRAINT FK_Publicaciones_Usuarios 
        FOREIGN KEY (UsuarioID) REFERENCES Usuarios(UsuarioID)
);

Consultas entre Tablas con JOINs

Los JOINs permiten combinar columnas de dos o más tablas en una sola consulta utilizando la relación existente entre sus claves.

INNER JOIN

Retorna solo los registros que coinciden en ambas tablas.

LEFT JOIN

Retorna todas las filas de la tabla izquierda y las coincidencias de la derecha.

RIGHT JOIN

Retorna todas las filas de la tabla derecha y las coincidencias de la izquierda.

Ejemplos Prácticos de JOIN

Consulta multitabla 
-- INNER JOIN: Obtener publicaciones junto al nombre de su autor
SELECT Publicaciones.Titulo, Publicaciones.Contenido, Usuarios.Nombre
FROM Publicaciones
INNER JOIN Usuarios ON Publicaciones.UsuarioID = Usuarios.UsuarioID;

-- LEFT JOIN: Mostrar TODOS los usuarios, tengan o no publicaciones
SELECT Usuarios.Nombre, Publicaciones.Titulo
FROM Usuarios
LEFT JOIN Publicaciones ON Usuarios.UsuarioID = Publicaciones.UsuarioID;

Subconsultas (Subqueries)

Una subconsulta es una consulta `SELECT` anidada dentro de otra instrucción SQL (`SELECT`, `INSERT`, `UPDATE` o `DELETE`).

1. Subconsulta Escalar en la Cláusula WHERE

-- Usuarios cuyo gasto supera el promedio general de todas las compras
SELECT Nombre, PrecioUltimaCompra
FROM Usuarios
WHERE PrecioUltimaCompra > (
    SELECT AVG(PrecioUltimaCompra) FROM Usuarios
);

2. Subconsulta con el Operador IN

-- Obtener datos de usuarios que hayan creado al menos una publicación
SELECT Nombre, Email
FROM Usuarios
WHERE UsuarioID IN (
    SELECT DISTINCT UsuarioID FROM Publicaciones
);

Consultas Avanzadas: CTEs, Vistas y Operadores de Conjunto

Herramientas avanzadas para estructurar código modular, simplificar consultas repetitivas y unificar conjuntos de datos.

1. Expresiones de Tabla Comunes (CTE - Common Table Expressions)

Permiten crear un conjunto de resultados temporal accesible dentro de una instrucción SQL posterior mediante la palabra clave WITH.

WITH UsuariosVIP AS (
    SELECT UsuarioID, Nombre, PrecioUltimaCompra
    FROM Usuarios
    WHERE PrecioUltimaCompra >= 3000
)
SELECT Nombre, PrecioUltimaCompra 
FROM UsuariosVIP 
ORDER BY PrecioUltimaCompra DESC;

2. Vistas Reutilizables (CREATE VIEW)

Una vista guarda la estructura de una consulta en la base de datos para ejecutarla como si fuera una tabla virtual.

CREATE VIEW vw_ResumenUsuarios AS
SELECT U.Nombre, U.Email, COUNT(P.PublicacionID) AS TotalPublicaciones
FROM Usuarios U
LEFT JOIN Publicaciones P ON U.UsuarioID = P.UsuarioID
GROUP BY U.Nombre, U.Email;
GO

-- Consultar la vista creada
SELECT * FROM vw_ResumenUsuarios WHERE TotalPublicaciones > 0;

3. Unificación de Consultas con UNION

-- Unir dos consultas eliminando duplicados
SELECT Email FROM Usuarios
UNION
SELECT Email FROM ClientesExternos;

Integración con Node.js y Express

Conexión de tu servidor Backend Node.js con Microsoft SQL Server mediante la librería oficial mssql.

1. Instalación de Dependencias

npm install mssql dotenv

2. Código de Conexión en JavaScript

db.js 
const sql = require('mssql');

const config = {
    user: 'sa',
    password: 'TuPasswordSeguro123',
    server: 'localhost',
    database: 'SistemaUsuarios',
    options: {
        encrypt: false,
        trustServerCertificate: true
    }
};

async function conectarBD() {
    try {
        await sql.connect(config);
        console.log("✅ Conexión exitosa con Microsoft SQL Server");
    } catch (error) {
        console.error("❌ Error de conexión:", error);
    }
}

module.exports = { sql, conectarBD };
