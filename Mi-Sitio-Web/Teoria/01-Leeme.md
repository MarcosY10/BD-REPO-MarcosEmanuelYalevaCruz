# Proyecto Web — Teoría SQL

El objetivo será desarrollar un sitio web donde se presente de manera clara y organizada la teoría de **SQL** trabajada durante las clases.

Para desarrollar el proyecto podrán utilizar **Inteligencia Artificial como herramienta de apoyo**.

El sitio se irá mejorando y corrigiendo durante las próximas clases.

## Organización del proyecto web

El desarrollo del sitio deberá realizarse dentro de:

```text
Mi-Sitio-Web/
└── Web-01/
```

Dentro de la carpeta **`Web-01`** deberán guardar **todos los archivos necesarios para que el sitio funcione correctamente**.

Por ejemplo:

```text
Mi-Sitio-Web/
└── Web-01/
    ├── index.html
    ├── css/
    │   └── styles.css
    ├── js/
    │   └── script.js
    └── img/
        └── imagenes
```

**Importante:** no guardar archivos del sitio fuera de `Web-01`.

La idea es que cada proyecto web quede correctamente organizado y pueda ejecutarse utilizando solamente el contenido de su carpeta.

## Tips básicos de diseño

### 1. Pensar antes de programar

Antes de pedirle código a una IA, pensar:

* ¿Cómo quiero que se vea mi página?
* ¿Dónde estará el menú?
* ¿Dónde estará el contenido?
* ¿Cómo voy a separar los diferentes temas?
* ¿Cómo encontrará el usuario lo que busca?

No comenzar directamente escribiendo código.

---

### 2. Mantener un diseño simple

No es necesario llenar la página de elementos.

Un diseño sencillo y ordenado suele funcionar mejor que uno con demasiados efectos.

> Menos puede ser más.

---

### 3. No utilizar demasiados colores

Elegir una pequeña paleta de colores y mantenerla durante todo el sitio.

Evitar que cada sección tenga colores completamente diferentes.

---

### 4. Mantener los mismos estilos

Si dos elementos cumplen la misma función, deberían verse similares.

Por ejemplo:

* Los títulos deberían mantener un mismo estilo.
* Los botones deberían ser similares.
* Las tarjetas deberían seguir el mismo diseño.
* Los ejemplos SQL deberían verse iguales entre sí.

Esto genera **consistencia visual**.

---

### 5. Diferenciar títulos y contenido

El usuario debe poder reconocer rápidamente:

* Título principal.
* Títulos de secciones.
* Subtítulos.
* Texto.
* Ejemplos de código.

No todo debe tener el mismo tamaño ni la misma importancia visual.

---

### 6. Utilizar espacios

No colocar todos los elementos pegados.

Dejar espacio entre:

* Títulos.
* Párrafos.
* Tarjetas.
* Imágenes.
* Bloques de código.
* Secciones.

El espacio también forma parte del diseño.

---

### 7. Facilitar la navegación

El usuario debería poder entender rápidamente:

* Dónde está.
* Qué temas existen.
* Cómo cambiar de tema.
* Cómo volver al inicio.

La navegación debe ser sencilla.

---

### 8. Pensar en quién utilizará la página

No diseñamos solamente para nosotros.

Preguntarse:

> ¿Una persona que entra por primera vez entendería cómo utilizar este sitio?

---

### 9. Pensar en diferentes pantallas

El sitio no debería estar pensado solamente para una computadora.

Durante el desarrollo tendremos en cuenta cómo se comporta en:

* Computadora.
* Tablet.
* Celular.

---

### 10. Utilizar IA con criterio

Pueden pedirle ayuda a una Inteligencia Artificial para generar código, mejorar diseños o solucionar problemas.

Pero recuerden:

> **La IA propone. Ustedes deciden.**

No acepten automáticamente todo lo generado.

Revisen el resultado, modifíquenlo y pregúntense si realmente cumple con lo que quieren construir.

---

## Importante

Este proyecto **no tiene que quedar perfecto en la primera clase**.

Durante las clases iremos revisando los sitios, detectando problemas y realizando mejoras.

El objetivo no será solamente terminar una página web, sino aprender progresivamente **cómo diseñar un sitio que sea claro, ordenado y fácil de utilizar**.
